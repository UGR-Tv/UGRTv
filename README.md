# UGR TV — V15 Launch Candidate

A static, streaming-style catalog for the public UGR releases.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. In **Settings → Pages**, select deployment from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Notes
- This is a static HTML site; no backend is required.
- Language selection supports Portuguese (Brazil), English, and Spanish. Preferences, watch progress, and lists are stored in the visitor's browser.
- Videos use YouTube embeds/links.
- Only publicly announced catalog entries should be listed.
